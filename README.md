# slop-sink

**An Open Slop Society project.**

This repository accepts pull requests without judging whether they are good ideas.

Useful changes are welcome. Useless changes are welcome. AI-generated changes are welcome. Low-effort changes are welcome. Ads are welcome. Rewrites are welcome. Unnecessary features are welcome.

If a pull request can be merged and does not violate the small set of non-negotiable rules below, the default outcome is **merge**.

## The rules

1. **0BSD stays.** This repository and contributions to it must remain distributable under the BSD Zero Clause License. Pull requests that remove, replace, restrict, or contradict that licensing policy will be rejected.
2. **GitHub and the law still apply.** Content that cannot legally be distributed here, or that violates GitHub's applicable Terms or Acceptable Use Policies, will be rejected or removed.
3. **Abuse is moderation, not slop.** Malware, credential theft, destructive payloads, or changes primarily intended to compromise contributors, users, maintainers, infrastructure, or third parties may be rejected.
4. **Make it mergeable.** If GitHub cannot cleanly merge the pull request into `main`, resolve the conflict and try again.

That is the quality bar. There is no quality bar beyond it.

## What are we building?

Whatever gets merged.

There is no roadmap and no requirement that the repository continue serving its current purpose. A pull request may add a tiny feature, replace the architecture, turn the project into something else, or make a decision nobody asked for.

Maintainer review is **moderation, not quality control**.

We do not reject a pull request because it is:

- poorly motivated
- unnecessary
- ugly
- overengineered
- underengineered
- AI-generated
- commercially motivated
- an advertisement
- a rewrite
- strange

If you think it should exist, submit it.
